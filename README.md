# Hotel Booking Performance & Customer Behavior Analysis

## About the Project

This is one of the projects I completed during my Business & Marketing Analytics training.

In this project, I worked with hotel booking data to understand booking patterns, revenue, cancellations, customer behaviour and higher-risk bookings.

The dataset contained **30,000 Resort Hotel booking records** covering the 2015–2017 arrival period.

## What I Worked On

- Cleaned and prepared the booking data using Excel and Power Query
- Checked data types, missing values and useful calculated fields
- Used SQL to answer booking and customer-related questions
- Built relationships and measures in Power BI
- Created two dashboards for overall performance and priority analysis
- Reviewed booking trends, revenue, cancellations, lead time and customer patterns

## Tools Used

- Microsoft Excel
- Power Query
- SQL / MySQL-style analysis
- Power BI
- DAX

## What I Learned

This project helped me practice:

- Preparing data before analysis
- Using SQL for business questions
- Creating useful calculated fields and measures
- Building Power BI dashboards
- Understanding booking and cancellation patterns
- Presenting findings in a simple way
